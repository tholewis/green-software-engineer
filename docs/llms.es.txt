# Ingeniero de software verde para Claude Code

> Agente y skill de Claude Code en español para integrar prácticas de la Green Software Foundation (GSF) en flujos de desarrollo.

## Componentes españoles

- Agente `ingeniero-software-verde`: consultoría sobre sostenibilidad, arquitectura, revisiones de código y medición SCI; seleccionar con `@` o invocar manualmente mediante `@agent-ingeniero-software-verde`.
- Skill `/revision-verde`: revisión estructurada que puede cargarse al trabajar con backend, datos, infraestructura, cachés o IA.

## Instalación

Copiar `.claude/agents/ingeniero-software-verde.md` y `.claude/skills/revision-verde/SKILL.md` en el directorio `.claude/` del proyecto o en `~/.claude/` para uso global.

## Conceptos principales

- GSF: Green Software Foundation.
- SCI: Intensidad de Carbono del Software, definida por ISO/IEC 21031:2024.
- Fórmula: `SCI = ((E × I) + M) / R`.
- E: energía; I: intensidad de carbono; M: emisiones incorporadas; R: unidad funcional.
- SCI for AI: extensión para medir sistemas de IA desde las perspectivas del consumidor y del proveedor.
